## Implementation assumptions

- Repository-native TypeScript validation is retained because the project has no Zod dependency.
- The existing SCRIMED Work router, learning loop, agent registry, audit utilities, and feature flags remain the single control plane.
- Durable CaseEvidence and assurance storage are not activated. A private append-only migration contract now exists locally; reviewed migration application, AAL2 RPCs, retention/legal-hold policy, and legal/governance approval remain prerequisites.
- Durable CaseEvidence storage is not activated; the local migration adds a reviewable schema contract without enabling a write path.
- Imaging integration handles synthetic metadata and FHIR previews only. DICOM pixel interpretation, live PACS/RIS/VNA connectivity, DiagnosticReport finalization, and EHR writeback remain blocked.
- All benchmark, evidence, routing, and value outputs are synthetic/internal and require qualified human review before any external claim.
