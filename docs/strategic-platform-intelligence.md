Each scorecard retains:

- Command lane
- Score state
- Evidence state
- Strategic signal

- Missing proof
- Leading indicator

- Next checkpoint
- Escalation path
- Promotion criteria
- Demotion triggers
- Retained boundary

The scorecards split current motion into active, watch, sequenced, proof-ready, proof-building, and external-review-required states. This makes the safest current position visible: SCRIMED can sell no-PHI proof, demos, readiness assessments, interoperability planning, and diligence while keeping clinical production, PHI, live connectors, security/certification claims, public API SLAs, and investor/legal/accounting commitments behind qualified review.

## Product Boundary

This layer does not assert third-party partnerships, copy third-party product claims, certify compliance, or authorize live clinical execution. It is a strategy-to-product translation layer for governed synthetic pilots and enterprise evaluation.
