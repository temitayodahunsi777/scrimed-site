# Healthcare Prosperity Charter

SCRIMED measures whether governed intelligence returns useful, evidence-supported value to
patients, clinicians, health systems, and communities. Activity volume is not a success metric.

## Verified Intelligence Yield

`accepted evidence-supported outputs / (inference cost + latency burden + human correction burden)`

Every input has a unit, evidence status, evidence reference, and stable identity. The weakest
input evidence status governs the result. A zero denominator returns no ratio.

## Healthcare Value Returned

The planning framework can represent patient cost, clinician time, administrative waste,
denial prevention, access, underserved reach, education, workforce training, community
reinvestment, and shared savings. Normalized value points are divided by operating and AI cost
only when the cost is nonzero.

All dashboard values in the current candidate are explicitly simulated. They are not audited
financial results, production ROI, customer outcomes, clinical validation, reimbursement
assurance, investment advice, or a public performance claim. External use requires verified
evidence, finance review, claims/legal review, publication permission, and exact candidate-bound
approval.
