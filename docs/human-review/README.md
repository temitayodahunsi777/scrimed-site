# Human Review Packets

These packets are concise decision aids, not approvals. Before use, attach the final generated
candidate packet and replace each `[FINAL 64-HEX]` field from that same unchanged candidate.
Reject stale, dirty-worktree, mismatched, expired, self-signed, or manually invented evidence.

Recommended dispositions apply only to synthetic, no-PHI, nonclinical pre-production scope.
Production migration, deployment, PHI, clinical action, payer/EHR/device action, certification
claims, and customer go-live require separate explicit authority.
