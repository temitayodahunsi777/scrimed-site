# SCRIMED Model Routing

## Policy Profiles

- Luna executes: low-consequence extraction, classification, routing, and formatting.
- Terra coordinates: balanced operational workflows, document analysis, and agent coordination.
- Sol resolves: hardest reasoning, research, architecture, security, conflicting evidence, and failed-verification escalation.

These are policy classes, not vendor model names. Providers are adapter-configured and unavailable until intentionally configured. Routing considers complexity, consequence, modality, data classification, residency, latency, budget, tenant policy, verification strength, and private-inference requirements.

No fallback may weaken privacy, residency, security, evidence, or clinical-safety requirements. PHI-prohibited and prohibited-risk requests are blocked before model selection. Confidence remains a routing signal, never proof of correctness.

Effective cost includes API, infrastructure, human review, retries, fallbacks, and expected failure cost. Efficiency frontiers are workflow-specific and require measured pilot evidence.
