# Founder Decisions Required

Only decisions requiring founder authority are listed here. Missing decisions default to the
safe action shown.

| Decision | Recommendation / consequence | Deadline | Default safe action |
| --- | --- | --- | --- |
| Interim pre-production acceptance | Accept only an exact immutable candidate for synthetic internal/preview use | Before preview | Continue local synthetic development only |
| Verified legal entity identity | Confirm counsel-reviewed entity name | Before binding contract/public legal adoption | Use non-binding SCRIMED product name only |
| Public address posture | Approve verified address or no-address posture | Before legal policy adoption | Publish no street address |
| Legal-review engagement | Retain qualified healthcare/privacy counsel | Before commercial healthcare deployment | Interim policies only |
| Privacy contact | Name accountable privacy contact | Before collecting commercial/customer data | Public forms remain no-PHI/minimum-data |
| Regulatory strategy owner | Name qualified owner | Before intended-use expansion | Research/demo/decision-support boundary |
| Named reviewers | Appoint security, clinical safety, legal, database, finance, and release owners | Before candidate promotion | All corresponding gates remain open |
| Preview deployment authorization | Name exact commit, operator, expiry and rollback | Before preview | No preview deployment |
| Disposable migration test | Authorization already limited to exact isolated dry run; appoint DB owner | Before execution | Static review only |
| Production migration/deployment | Decide only after all prerequisite evidence and approvals | Later separate decisions | Disabled |
| Customer go-live / PHI / EHR/device | Customer-specific and professional review required | Later separate decisions | Disabled |
| Material spend / binding contracts / fundraising or equity | Founder decision with finance/counsel evidence | Before commitment | No commitment |
