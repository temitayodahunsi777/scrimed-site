# Human-Gate Minimization Report

**Machine-readable artifact:** `artifacts/governance/human-gate-minimization.json`

SCRIMED separates evidence preparation from accountable authority. The 13 external p.32 gates
are classified as:

| Class | Count | Meaning |
| --- | ---: | --- |
| Human accountability required | 10 | A qualified named owner must accept responsibility for the exact scope and candidate |
| Commercial authority required | 1 | Customer go-live requires buyer and SCRIMED authority |
| Operator action required | 2 | Real AAL2 evidence and post-deployment checks require an authorized operator |
| Automated external gate | 0 | No external decision can be converted into authority by software |

Automation prepares source manifests, fingerprints, test evidence, risk summaries, review
packets, claim checks, migration evidence, provider records, monitoring plans, and rollback
evidence. It does not automate legal adoption, clinical responsibility, privacy/security risk
acceptance, migration approval, deployment authorization, binding commercial authority, customer
activation, or external distribution authority.

Synthetic fixtures can test validators but can satisfy none of the 13 gates. Every approval must
remain scoped, fresh, attributable, and bound to the exact candidate.
