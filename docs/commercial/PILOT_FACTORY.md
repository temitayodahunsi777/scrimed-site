# Synthetic Pilot Factory

The pilot factory provides a repeatable no-PHI path:

1. Discovery
2. Workflow map
3. Synthetic baseline
4. Success criteria
5. Implementation
6. Evaluation
7. Executive readout
8. Expansion hypothesis

Every pilot is labeled `SYNTHETIC`, preserves a workflow twin, and produces an evidence pack containing objective, baseline, workflow, intervention, evidence requirements, limitations, cost/value availability, safety status, and an independently reviewable expansion decision.

The first template is Documentation Before Authorization. It detects documentation gaps against synthetic payer-policy fixtures and prepares a cited draft. It cannot determine coverage, submit to a payer, change coding, mutate a claim, write to an EHR, or make a clinical decision.

## Expansion gate

Expansion requires measured baseline evidence, reviewer acceptance, no-PHI and policy checks, named owners, security/privacy/legal review appropriate to scope, and a separate authorization. Synthetic results are not customer outcomes, denial reduction, savings, ROI, or production evidence.
